# MacciellBarber - Landing Page Premium

Este es un proyecto web minimalista y elegante para la barbería **MacciellBarber**. Diseñado con una estética monocromática inspirada en la moda y el comercio electrónico de alta gama.

## Características

- 📱 **Diseño 100% Responsivo**: Mobile-First, optimizado para celulares y tablets.
- 🎨 **Estilo Visual Moderno**: Paleta de colores en escala de grises, negro profundo y blanco. Uso de tipografías premium (`Outfit` e `Inter`).
- ⚡ **Animaciones Fluidas**: Efectos hover interactivos y animaciones de entrada suaves (fade-in) al hacer scroll.
- 💬 **Llamados a la Acción (CTA)**: Integración directa con WhatsApp para agendamiento rápido de turnos con un mensaje preestablecido.
- 🛠️ **Arquitectura Limpia**: Desarrollado con HTML5 semántico, CSS Vanilla estructurado y JavaScript modular básico.

## Estructura del Proyecto

```text
macciellbarber-web/
├── assets/          # Imágenes de barbería de alta calidad (generadas)
├── index.html       # Estructura de la Landing Page
├── style.css        # Hoja de estilos con variables y CSS Grid/Flexbox
├── app.js           # Lógica JavaScript para menú móvil y animaciones
└── README.md        # Documentación del proyecto
```

## Configuración y Ejecución

1. Abre el archivo `index.html` en tu navegador favorito para previsualizar.
2. O inicia un servidor local (por ejemplo, con la extensión *Live Server* de VS Code o ejecutando `npx serve .` en la terminal).
